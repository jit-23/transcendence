const io = new Server(server, {
  cors: {
    origin: "http://localhost:5173",
  }
});

io.on("connection", (socket) => {
  // 1. Get username from auth
  const username = socket.handshake.auth.username as string;

  if (!username) {
    return socket.disconnect();
  }

  // 2. Map username to the current socket ID
  connectedByName.set(username, socket.id);
  console.log(`${username} connected with ID: ${socket.id}`);

  // 3. Private Message Listener (MUST be inside the connection block)
  socket.on("private-message", ({ payload }: { payload: { to: string, text: string } }) => {
    const toSocketId = connectedByName.get(payload.to);
    
    if (toSocketId) {
      // Send to the specific recipient
      io.to(toSocketId).emit("private-message", { 
        from: username, 
        text: payload.text 
      });
    } else {
      // Let the sender know the user is offline
      socket.emit("user-not-found", { to: payload.to });
    }
  });

  // 4. Disconnect Logic
  socket.on("disconnect", () => {
    connectedByName.delete(username);
    console.log(`${username} disconnected`);
  });
});

// ... (Prisma SIGINT remains the same)

Key Changes Made:

    Moved Listeners Inside: I moved socket.on("private-message") and socket.on("disconnect") inside the io.on("connection") callback. This gives them access to the specific socket instance and the username variable.

    Explicit Typing: For the error error TS7031: Binding element 'payload' implicitly has an 'any' type, I added a type inline: ({ payload }: { payload: { to: string, text: string } }).

    Accessing username: By keeping the logic inside the connection scope, the username variable is "captured" in a closure, so it's available whenever that specific user sends a message or disconnects.

A Quick Tip on Scaling

Using a Map is great for a single-server setup. If you eventually decide to scale to multiple server instances (using a load balancer), you'll want to look into the @socket.io/redis-adapter, as a Map only lives in the memory of one specific server!
