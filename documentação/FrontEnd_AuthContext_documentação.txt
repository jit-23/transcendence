este ficheiro é primordial para poder trabalhar com a informação do user.

a syntax desta função é peculiar:

export function AuthProvider({ children })

this is a : Higher-Order Component (HOC) that implements the Provider Pattern

este procedimento tem como objetivo dar fetch a informação do user (neste caso) e encapsular a App, a volta deste  Component Composition.

no main o authProvider será usado para envolver o resto do codigo do frontend:

ReactDOM.createRoot(document.getElementById("root")!).render(
        <ThemeProvider>
            <AuthProvider>
                <App />
            </AuthProvider>
        </ThemeProvider>
)


como podemos ver a App/ está a volta do AuthProvider/

assim qualquer funcao ou metodo dentro do app poderá aceder a info do user fetched 
no AuthProvider
